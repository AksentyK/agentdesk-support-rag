# Как передать проект в Codex

1. Создайте репозиторий `agentdesk-support-rag` (приватный) и загрузите файлы комплекта.
2. В Codex откройте этот репозиторий и отправьте текст из раздела 11 файла `CODEX_TECHNICAL_SPEC.md`.
3. Секреты передайте Codex **только через безопасное управление переменными окружения среды** или через локальный `.env.local`, не через коммит в Git. `.env.example` — шаблон без реальных значений.
4. Укажите точные ID двух выбранных моделей RouterAI в `BASELINE_MODEL_ID` и `STRONG_MODEL_ID` и реальный ключ в `ROUTERAI_API_KEY`.
5. Убедитесь, что сборка и тесты проходят, затем протестируйте четыре режима и сравните ответы, ссылки, задержку, стоимость.
6. Результаты holdout не использовать при редактировании промпта.

**Важно:** продукт AgentDesk вымышлен; создаваемое приложение — AI-оператор поддержки по его базе знаний. PDF на 35 страниц создан как фиксированный печатный вариант, Markdown — источник для RAG. Один и тот же материал дважды не индексируйте.
